# Exploratory Analysis with a Finding

## IBM HR Analytics – Employee Attrition

### Project Overview

This project explores the IBM HR Analytics Employee Attrition dataset using Python to identify factors associated with employee turnover.

### Objectives

* Analyze employee attrition patterns.
* Explore overtime, job satisfaction, income, and job roles.
* Visualize findings using charts.
* Statistically examine the association between overtime and attrition.

### Tools and Technologies

* Python
* Google Colab
* Pandas
* NumPy
* Matplotlib
* Seaborn
* SciPy

### Key Finding

Employees working overtime had a 30.53% attrition rate, compared with 10.44% among employees who did not work overtime.

A Chi-square test found a statistically significant association between overtime and attrition.

### Conclusion

The analysis provides insights into employee turnover patterns and suggests areas where organizations can investigate employee retention challenges.
